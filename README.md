Task 4 — Rock-Paper-Scissors Game

Description

This is a simple command-line game developed using Python. The user chooses rock, paper, or scissors, and the computer randomly selects one option. The program determines the winner based on the game rules.

Features

- User input for rock, paper, or scissors
- Random computer selection
- Winner determination
- Score tracking across multiple rounds
- Option to play again
- Input validation

Technologies Used

- Python
- random module
- VS Code

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python rock_paper_scissors.py

Game Rules

- Rock beats scissors.
- Scissors beat paper.
- Paper beats rock.
- Matching choices result in a tie.
